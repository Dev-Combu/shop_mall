# 🔐 Cafe24 쇼핑몰 네이티브 회원가입/로그인 연동 및 회원 정보 확인 페이지 구축

**작성일시**: 2026-10-16  
**작업 브랜치**: `feat/auth`  
**관련 이슈**: 수지씨앤엘 쇼핑몰(`suzicnl.com` / `suzicnl1`) 실시간 고객 계정 연동 및 회원 정보 확인 화면 신설

---

## 1. 개요 및 배경
- **문제점**:
  1. 앱 내에서 회원가입 및 로그인 시 실제 Cafe24 쇼핑몰(`suzicnl.com`) 서버로 데이터가 전달되지 않거나, 직접 HTTP 전송 시 Cafe24의 `AuthSSLManager` 보안 암호화 누락으로 `"잘못된 요청입니다."` 오류가 발생함.
  2. 가입/로그인된 회원의 아이디, 이름, 연락처, 적립금, 쿠폰, 등급 등 실제 Cafe24 고객 데이터를 상세하게 조회하고 관리할 수 있는 전용 확인 페이지가 부재함.
- **해결 방안**:
  1. 외부 웹뷰를 띄우지 않고 100% 네이티브 UI([`LoginPage`](../lib/views/login.dart), [`SignUpPage`](../lib/views/signup.dart))를 유지하면서, 백그라운드 WebKit 엔진을 통해 Cafe24 공식 `AuthSSLManager` 암호화 및 jQuery 중복확인 이벤트를 완벽하게 실행하여 실제 Cafe24 관리자 사이트(`고객 관리 > 회원 조회`)에 회원이 즉시 등록되도록 구현.
  2. 가입/로그인된 회원의 상세 정보를 직관적으로 확인할 수 있는 **회원 정보 확인 페이지([`ProfilePage`](../lib/views/profile.dart))**를 신설하고 라우터 및 마이페이지에 연동.

---

## 2. 주요 구현 내용

### 1) 회원 정보 확인 페이지 (`lib/views/profile.dart`) 신설
- **회원 프로필 요약 카드**:
  - 이름, 회원 등급 뱃지, 회원 아이디
  - **`Cafe24 공식 쇼핑몰 연동 계정`** 인증 뱃지 표시
- **쇼핑 혜택 및 활동 현황 카드**:
  - 가용 적립금 (P), 보유 쿠폰 (장), 누적/진행 주문 건수 (건)
- **기본 회원 정보 상세 카드**:
  - 회원 아이디, 이름(실명), 이메일 주소, 휴대폰 번호, 회원 등급
- **Cafe24 쇼핑몰 연동 상태 카드**:
  - 연동 쇼핑몰: 수지씨앤엘 (`suzicnl.com`)
  - 몰 아이디: `suzicnl1`
  - 인증 체계: Cafe24 AuthSSL 암호화 세션
  - 보안 저장소: `FlutterSecureStorage` (기기 보안 암호화 보관)
- **주요 기능**:
  - 상단 새로고침 버튼 (`Pull-to-Refresh` 지원)
  - 하단 로그아웃 버튼 (확인 다이얼로그 연동)

### 2) 라우터 및 마이페이지 연동
- **`lib/config/router/router.dart`**:
  - `/profile` 라우트 등록 (`GoRoute(path: '/profile', name: 'profile', builder: ...)`)
- **`lib/views/my_page.dart`**:
  - 로그인된 상단 프로필 헤더 클릭 시 `/profile`로 바로 이동하도록 `InkWell` 및 `chevron_right` 적용
  - 마이페이지 설정 목록에 **`[내 정보 및 계정 관리] > [회원 정보 확인]`** 메뉴 아이템 추가

### 3) 100% 네이티브 AuthSSL 백그라운드 엔진 (`login.dart`, `signup.dart`)
- 비가시성(1x1 투명) WebKit 엔진을 통해 Cafe24의 `AuthSSLManager` 일회용 SSL 공개키 암호화를 수행하여 `"잘못된 요청입니다."` 해결
- Cafe24 비밀번호 복잡도 규칙(영문/숫자/특수문자 조합) 및 휴대폰 번호 분할 전송(`mobile[]`) 완벽 준수
- Cafe24 JavaScript `alert()`을 `setOnJavaScriptAlertDialog`로 가로채어 네이티브 인라인 에러 박스로 자연스럽게 노출

---

## 3. 검증 결과
- **회원가입**: 앱에서 신규 회원 가입 시 Cafe24 쇼핑몰 관리자(`고객 관리 > 회원 조회`)에 실시간으로 회원이 등록됨.
- **로그인 & 마이페이지**: 가입된 계정으로 로그인 시 마이페이지 및 회원 정보 확인 페이지(`/profile`)에 실시간 데이터 바인딩 정상 작동.
- **새로고침 & 로그아웃**: 회원 정보 확인 페이지에서 새로고침 및 로그아웃 정상 동작.
